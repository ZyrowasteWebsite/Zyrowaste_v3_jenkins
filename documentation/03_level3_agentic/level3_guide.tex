\section{Goal}

Introduce a \textbf{multi-tool agent} that \textbf{reasons} over user queries and add a \textbf{dedicated certifications showcase}. Include \textbf{basic scraping} for market intelligence.

\section{Agentic RAG}

The \textbf{agent} receives a query and \textbf{decides which tools} to call. Typical tools:

\begin{tabular}{@{}lp{7.5cm}@{}}
\toprule
\textbf{Tool} & \textbf{Purpose} \\
\midrule
\textbf{VectorSearchTool} & Semantic retrieval from Chroma / Qdrant \\
\textbf{FinancialCalculatorTool} & ROI, margins, or unit economics helpers \\
\textbf{CertificationLookupTool} & Structured lookup of ISO records \\
\textbf{WebSearchTool} & Optional live web augmentation (rate-limited, cited) \\
\bottomrule
\end{tabular}

\textbf{Multi-step reasoning example:} User asks for \textit{``Compare our ISO scope to last year's revenue assumption in the project report.''} The planner might (1) run \textbf{CertificationLookupTool} for scope text, (2) run \textbf{VectorSearchTool} on the report for financial assumptions, (3) synthesize a comparison with citations.

\section{Certifications Page}

\begin{itemize}[leftmargin=*]
  \item Display \textbf{ISO 9001:2015} and \textbf{ISO 13485:2016} with \textbf{structured fields}: certificate number, issue/expiry dates, scope of certification.
  \item \textbf{PDF viewer} or \textbf{download} links per certificate.
  \item \textbf{Admin form} (protected route) to add or update certificates, backed by \textbf{SQLite} for simplicity.
\end{itemize}

\section{Basic Scraping}

\begin{itemize}[leftmargin=*]
  \item Scripts under something like \texttt{backend/scrapers/} scrape \textbf{biodegradable plastics market data} from \textbf{public} sources.
  \item Store normalized output as \textbf{JSON} under \textbf{\texttt{\_0\_Resources/\_scraped/}} (gitignore large or sensitive pulls if needed).
\end{itemize}

\section{Implementation Steps}

\begin{enumerate}[leftmargin=*]
  \item \textbf{Build} the agent graph with \textbf{LangGraph} (or CrewAI crews) and shared tool interfaces.
  \item \textbf{Create} tool functions with clear schemas and unit tests where practical.
  \item \textbf{Migrate} the frontend to \textbf{Next.js} (App Router), preserving chat and branding.
  \item \textbf{Build} the \textbf{certifications} page with structured data components and PDF actions.
  \item \textbf{Create} scraping scripts with scheduling hooks (manual cron or later Airflow).
  \item \textbf{Add} \textbf{\texttt{docker-compose.yml}} for local backend + DB + optional vector store.
\end{enumerate}
