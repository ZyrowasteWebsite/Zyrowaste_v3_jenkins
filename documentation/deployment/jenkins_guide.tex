\section{Overview}
This guide restores \textbf{zyrowaste.com} after moving from ad-hoc Docker to a Jenkins-driven production pipeline with rolling deploys, health gates, and automatic rollback.

\section{Architecture}
Internet traffic hits DNS for \texttt{zyrowaste.com}, then the droplet nginx edge on ports 80/443. Path \texttt{/} proxies to the frontend container; \texttt{/api/} proxies to the FastAPI backend. Backend depends on Postgres, Redis, and ChromaDB. Jenkins builds and pushes images, SSHs to the droplet, and performs a rolling recreate (backend $\rightarrow$ health $\rightarrow$ frontend $\rightarrow$ nginx reload). Failed smoke tests roll back to the previous image tag.

\section{Prerequisites}
\begin{itemize}
  \item Droplet/VPS with public IP (2 vCPU / 4\,GB+ recommended).
  \item DNS A records for \texttt{zyrowaste.com} and \texttt{www} pointing at the droplet.
  \item Container registry (GHCR or Docker Hub).
  \item Jenkins with Docker Pipeline, SSH Agent, Credentials Binding, and Git plugins.
\end{itemize}

\section{Part A --- Bring the droplet online (one-time)}

\subsection*{DNS}
Create A records for \texttt{@} and \texttt{www} to the droplet public IP. Verify with \texttt{dig +short zyrowaste.com}.

\subsection*{Bootstrap}
Run \texttt{scripts/jenkins/bootstrap-server.sh} as root, or install Docker manually and create \texttt{/opt/zyrowaste}.

\subsection*{Secrets}
Copy \texttt{.env.production.example} to \texttt{/opt/zyrowaste/.env.production}, set \texttt{chmod 600}, and fill \texttt{GROQ\_API\_KEY}, \texttt{JWT\_SECRET}, \texttt{POSTGRES\_PASSWORD}, \texttt{DATABASE\_URL}, and image names.

\subsection*{TLS}
Issue Let's Encrypt certificates into \texttt{infrastructure/nginx/ssl/live/zyrowaste.com/}. For first boot without certs, use \texttt{zyrowaste.http-bootstrap.conf}.

\begin{lstlisting}[language=bash]
docker run --rm -p 80:80 \
  -v /opt/zyrowaste/infrastructure/nginx/ssl:/etc/letsencrypt \
  certbot/certbot certonly --standalone \
  -d zyrowaste.com -d www.zyrowaste.com \
  --email admin@zyrowaste.com --agree-tos --non-interactive
\end{lstlisting}

\subsection*{Manual first deploy}
\begin{lstlisting}[language=bash]
docker build -t ghcr.io/zyrowaste/frontend:latest ./frontend
docker build -t ghcr.io/zyrowaste/backend:latest ./backend
cd /opt/zyrowaste
docker compose -f docker-compose.prod.yml --env-file .env.production up -d
curl -k https://zyrowaste.com/api/health
\end{lstlisting}

\section{Part B --- Jenkins end-to-end}

\subsection*{Install Jenkins (Ubuntu sketch)}
Install OpenJDK 17 and the Jenkins package, add the \texttt{jenkins} user to the \texttt{docker} group, and restart Jenkins. Install Docker Pipeline and SSH Agent plugins.

\subsection*{Credentials}
\begin{itemize}
  \item \texttt{docker-registry} --- username/password for GHCR or Docker Hub.
  \item \texttt{ssh-prod} --- SSH private key for the droplet deploy user.
\end{itemize}

\subsection*{Job configuration}
Create a Pipeline job from SCM, branch \texttt{main}, script path \texttt{Jenkinsfile}. Set optional env vars \texttt{DOCKER\_REGISTRY}, \texttt{IMAGE\_NAMESPACE}, and \texttt{PROD\_HOST} (prefer droplet IP for SSH).

\subsection*{SSH trust}
Generate an ed25519 key for the Jenkins user, install the public key on the droplet, and store the private key as credential \texttt{ssh-prod}.

\subsection*{Run}
Build with Parameters: \texttt{DEPLOY\_ENV=production}. Stages: Checkout, Validate, Lint, Test, Build, Scan, Push, Deploy, Smoke. Success means \texttt{https://zyrowaste.com} and \texttt{/api/health} are healthy.

\subsection*{Rollback}
Automatic on post-failure. Manual: set \texttt{IMAGE\_TAG\_OVERRIDE} to a previous build number, or restore \texttt{.previous\_tag} on the server.

\section{Zero-downtime behaviour}
Each deploy pulls new tags, recreates backend until healthy, recreates frontend until healthy, reloads nginx, then smoke-tests public HTTPS. Data volumes are preserved. Multi-replica blue/green requires Swarm/Kubernetes; rolling recreate is the practical single-droplet pattern.

\section{Go-live checklist}
\begin{itemize}
  \item[\(\square\)] DNS A records for @ and www
  \item[\(\square\)] Docker on droplet
  \item[\(\square\)] \texttt{.env.production} filled
  \item[\(\square\)] TLS certificates present
  \item[\(\square\)] Compose stack up
  \item[\(\square\)] Health endpoint returns healthy
  \item[\(\square\)] Jenkins credentials and job configured
  \item[\(\square\)] Green pipeline run
\end{itemize}

\section{Troubleshooting}
\textbf{502:} backend unhealthy --- check compose logs. \textbf{SSL/nginx fail:} missing certs --- use HTTP bootstrap or Certbot. \textbf{CORS:} set origins to https://zyrowaste.com. \textbf{SSH fail:} keys/firewall/\texttt{PROD\_HOST}. \textbf{Pull denied:} docker login on droplet.

\section{Security}
Keep secrets only on the server (\texttt{chmod 600}). Do not expose Postgres/Redis publicly. Rotate registry PATs and \texttt{JWT\_SECRET} if leaked. Protect Jenkins UI with auth and network controls.
