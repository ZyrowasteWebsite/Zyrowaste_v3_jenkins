\section{Level 1 Deployment}

\textbf{Vercel free:} 100GB bandwidth, serverless functions.

\textbf{Alternative:} GitHub Pages (static only).

\textbf{Steps:} Connect the GitHub repository, configure environment variables in the Vercel dashboard, and enable auto-deploy on push.

\section{Level 2 Deployment}

\textbf{Vercel} (frontend) + \textbf{Render.com free} (backend, 750h/month, spins down when idle).

\textbf{Alternatives:} HuggingFace Spaces, Railway at approximately \$5/month. ChromaDB on disk.

\section{Level 3 Deployment}

\textbf{Vercel} (frontend) + \textbf{Render} (backend) + \textbf{SQLite} file.

\textbf{Alternative:} Fly.io (3 free VMs).

\section{Level 4 Deployment}

Add \textbf{Supabase free} (500MB PostgreSQL) or \textbf{Neon.tech} (512MB). Airflow on a \$5/month DigitalOcean droplet or Astronomer free dev tier.

\section{Level 5 Deployment}

\textbf{Docker Compose} for all services. \textbf{DigitalOcean App Platform} (\$5/month) or \textbf{AWS Lightsail} (\$3.50/month). \textbf{GitHub Actions} CI/CD (2000 free minutes). \textbf{Sentry free} (5K errors). \textbf{UptimeRobot free} (50 monitors).

\section{Level 6 Deployment Budget Tiers}

\begin{itemize}[leftmargin=*]
  \item \textbf{\$0--10/month:} Oracle Cloud Free Tier (4 ARM A1, 24GB RAM) + K3s
  \item \textbf{\$10--50/month:} Hetzner CX21 (approximately \$5) or DigitalOcean K8s (\$12)
  \item \textbf{\$50--200/month:} AWS EKS Spot or GCP GKE Autopilot
\end{itemize}

\section{Always-Free Building Blocks}

Cloudflare CDN+DNS+SSL (free), Let's Encrypt, Cloudflare R2 / Backblaze B2 (10GB), approximately \$10/year for a \texttt{.in} domain.

\section{Docker Compose Example (Local Development)}

Services: \texttt{frontend}, \texttt{backend}, \texttt{chromadb}, \texttt{postgres}, \texttt{redis}, \texttt{airflow-webserver}, \texttt{airflow-scheduler}.

\begin{lstlisting}[language=dockercompose, caption={Illustrative local dev skeleton (\texttt{docker-compose.yml})}]
# docker-compose.yml (illustrative local dev skeleton)
services:
  frontend:
    build: ./frontend
    ports:
      - "3000:3000"
  backend:
    build: ./backend
    ports:
      - "8000:8000"
    depends_on:
      - postgres
      - redis
      - chromadb
  chromadb:
    image: chromadb/chroma
    ports:
      - "8001:8000"
  postgres:
    image: postgres:16
    environment:
      POSTGRES_USER: swaroop
      POSTGRES_PASSWORD: changeme
      POSTGRES_DB: swaroop
    ports:
      - "5432:5432"
  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
  airflow-webserver:
    image: apache/airflow:2.8.0
    command: webserver
    ports:
      - "8080:8080"
    depends_on:
      - airflow-scheduler
  airflow-scheduler:
    image: apache/airflow:2.8.0
    command: scheduler
\end{lstlisting}

\section{Production Checklist}

\begin{itemize}[leftmargin=*]
  \item SSL/TLS termination and certificate renewal
  \item Environment-specific configurations (dev/staging/prod)
  \item Health checks and readiness probes
  \item Backup strategy for databases and object storage
  \item Monitoring alerts (latency, errors, saturation)
  \item Log aggregation and retention
\end{itemize}
