\section{Goal}

Smart retrieval routing, interactive dashboards, and structured ETL.

\section{New Technology}

\begin{itemize}[leftmargin=*]
  \item \textbf{LangGraph} with routing (query classifier)
  \item \textbf{Plotly Dash} or \textbf{React + Recharts} for dashboards
  \item \textbf{PostgreSQL} (Supabase or Neon free tier)
  \item \textbf{Apache Airflow} for orchestration
\end{itemize}

\section{Adaptive RAG Pipeline}

A \textbf{query classifier LLM} routes incoming queries to:

\begin{enumerate}[leftmargin=*]
  \item \textbf{Vector RAG} -- factual and document-based queries
  \item \textbf{SQL RAG} -- financial and numeric queries
  \item \textbf{Web Search} -- real-time and market queries
  \item \textbf{Direct LLM} -- simple queries and greetings
\end{enumerate}

\section{Data Analysis Page (\texttt{/analytics})}

\begin{itemize}[leftmargin=*]
  \item Financial projections dashboard: Sales, EBITDA, Net Profit, and ROI by year
  \item Market comparison charts
  \item Risk matrix visualization
  \item CAPEX breakdown
  \item Sensitivity analysis (NPV / IRR)
\end{itemize}

\section{Data Scraping Sources}

\begin{itemize}[leftmargin=*]
  \item PLA / PBAT pricing from IndiaMART and Alibaba
  \item Market reports from Grand View Research
  \item Regulatory updates from CPCB and BIS
  \item Competitor intelligence, trade events, and government subsidies
\end{itemize}

\section{Implementation Steps}

\begin{enumerate}[leftmargin=*]
  \item Build the query classifier with LangGraph
  \item Create the SQL RAG chain
  \item Set up PostgreSQL with Alembic migrations
  \item Build dashboard components
  \item Create Airflow DAGs
  \item Connect the frontend analytics page
\end{enumerate}

\section{Deployment}

\begin{itemize}[leftmargin=*]
  \item \textbf{Database:} Supabase or Neon (free PostgreSQL)
  \item \textbf{Orchestration:} Self-hosted Airflow on a $\sim$\$5/month DigitalOcean droplet
  \item \textbf{Frontend:} Vercel
  \item \textbf{Backend:} Railway
\end{itemize}
