\section{ETL Pattern}

Extract (scraper) $\rightarrow$ Transform (clean, validate, normalize) $\rightarrow$ Load (PostgreSQL + ChromaDB). Incremental loading with upsert. Data quality checks. Error handling with retries.

\section{GenAI Automation}

Report Generator, Email Drafter, Social Media Content, Document Translator, Competitive Intelligence Summarizer --- all using free LLM APIs (Groq, HuggingFace).

\section{Data Versioning}

DVC or LakeFS free tier for tracking dataset changes.

\section{Storage}

Raw data in \texttt{\_0\_Resources/\_scraped/} as JSON. Processed data in PostgreSQL. Embeddings in ChromaDB/Qdrant.
